With `SAVE_ATTEMPTS=1`, each graded live reading is saved before the response as a UUID-named 16 kHz, mono, 16-bit PCM `.wav` and matching `.json` under `DATA_DIR/attempts` (default `data/attempts`), even if the turn is never finished; saving is off by default and excludes credentials, teacher PINs and voice-card audio.
The version 1 JSON names its WAV in `audio` and contains `turnId`, zero-based `setIndex` and `lineIndex`, `itemId`, bank `text`, `preset`, syllable arrays in `heard.raw`, `heard.metered` and `heard.final`, phoneme `tokens` (null if unavailable), graded `words`, `verdicts`, `summary`, and `timings.recordingMs` and `timings.gradeMs` (including queue time).
Play the referenced WAV to inspect the capture or feed its bytes to the ear without the JSON text; `tools/clip-recorder/replay.js` expects a named adult clip set and its separately recorded voice card, so this live format is documented separately and does not replace or write to those recordings.
