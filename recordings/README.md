# Recordings

Name each clip for the word being read, followed by the mistake planted in the
recording: `shabbos_va-for-ba.wav` means the word was shabbos and the reader said
`va` where `ba` belonged. Use `.wav`, `.mp3`, `.flac`, `.ogg`, or `.m4a`.

`recordings/private/` is gitignored because a child's voice never enters this
public repo, with or without consent. Keep children's recordings there locally.
Delete children's audio right after grading; store only verdicts.
