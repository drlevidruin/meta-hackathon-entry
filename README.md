# Kriah Listener

A classroom reading station for Hebrew with nekudos. A child reads one line from the screen. Meta's model hears the sounds without seeing the line, a rulebook knows what every letter and vowel should sound like, and a grader marks each one: right, wrong letter, wrong vowel, skipped, or extra.

Built for the Meta Global AI Developer Hackathon, October 26 to November 4, 2026. The plan and the rules this project follows are in [CLAUDE.md](CLAUDE.md).
